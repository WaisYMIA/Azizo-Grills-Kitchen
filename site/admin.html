Branches

Tick Show on website to list a branch for customers (branch strip, Find Us map, footer and the pickup / delivery pickers at checkout); untick to hide it without deleting anything. Use Edit to change a branch's address, map pin, hours and its own phone number. Every branch takes orders on the same WhatsApp number — a branch's phone is only the number customers call for that branch. Delivery fees are measured from each branch's map pin, so check the pins before listing a new branch. Hiding a branch (for example while it is closed) also re-routes delivery zones, quotes and the nearest-branch suggestions to the next nearest live branch - see the Areas tab.
